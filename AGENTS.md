## Описание проекта

Это клиентский каталог фильмов, созданный как учебный проект для изучения React, Redux Toolkit и RTK Query. Приложение получает данные из TMDB и поддерживает списки по категориям, поиск, фильтрацию, страницы фильмов и избранное, сохраняемое в браузере.

У приложения нет собственного бэкенда. Любые значения `VITE_*` являются публичной конфигурацией браузера, даже если они называются API-ключом или токеном.

## Технологии

- React 19 и TypeScript в строгом режиме
- Vite с React-плагином на базе SWC
- Redux Toolkit и React Redux
- RTK Query для всех запросов к TMDB
- React Router 7
- Material UI для переключателя темы и элементов фильтрации
- CSS Modules для остального интерфейса
- pnpm и `pnpm-lock.yaml`

## Настройка и команды

Используйте Node.js и pnpm. Создайте локальный файл `.env`:

```dotenv
VITE_BASE_URL=https://api.themoviedb.org/3
VITE_API_KEY=<TMDB-v4-read-access-token>
```

Не добавляйте в репозиторий `.env`-файлы и реальные учётные данные TMDB.

Основные команды:

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm preview
```

Если Windows блокирует выполнение PowerShell-скриптов, используйте `pnpm.cmd` вместо `pnpm`.

Автоматических тестов пока нет. После каждого изменения как минимум запускайте `pnpm build` и `pnpm lint`, а затем вручную проверяйте затронутый маршрут.

## Структура репозитория

- `src/main.tsx` подключает приложение, Redux Provider и браузерный роутер.
- `src/app/store.ts` настраивает редьюсеры `app`, `favorites`, RTK Query и API middleware.
- `src/app/baseApi.ts` содержит единственный экземпляр RTK Query API, базовый URL TMDB и заголовок авторизации.
- `src/app/app-slice.ts` хранит выбранную тему.
- `src/common/routing/Routing.tsx` содержит таблицу маршрутов и маршрутные константы.
- `src/common/components/` содержит общие карточки, шапку, подвал, пагинацию и страницу 404.
- `src/common/types/types.ts` содержит общие типы фильмов и пагинации TMDB.
- `src/features/main/` реализует главную страницу и превью четырёх категорий.
- `src/features/categoryMovies/` реализует страницы категорий с пагинацией.
- `src/features/search/` реализует поиск фильмов, связанный с URL.
- `src/features/filteredMovies/` реализует фильтры и сортировку TMDB Discover.
- `src/features/movie/` реализует информацию о фильме, актёрский состав и похожие фильмы.
- `src/features/favorites/` реализует Redux-срез и страницу избранного.
- `vercel.json` перенаправляет маршруты браузерного роутера на `index.html`.

## Архитектура и поток данных

Сохраняйте единственный RTK Query API slice. Новые эндпоинты TMDB добавляйте через `baseApi.injectEndpoints`. Не создавайте ещё один экземпляр `createApi` и не подключайте дополнительный API middleware.

Модули эндпоинтов экспортируют сгенерированные хуки, которые UI-компоненты вызывают напрямую. Серверные данные должны находиться в кеше RTK Query. Локальное состояние интерфейса, например номера страниц и активные фильтры, оставляйте в компонентах, если его не нужно разделять между компонентами или отражать в URL.

Redux Store содержит только:

- `app` — локальные настройки интерфейса;
- `favorites` — краткие данные об избранных фильмах с локальным сохранением;
- `tmdbApi` — кеш и состояние запросов RTK Query.

Для маршрутов используйте константы из `Routing.tsx`. Общие типы ответов TMDB размещайте в `src/common/types`, а специфичные для отдельной функциональности — в каталоге `lib` соответствующей feature.

Алиас `@/` указывает на `src/`. Используйте его для импортов между функциональными модулями, а относительные импорты — внутри небольшого локального каталога компонента.

## Правила реализации

- Сохраняйте строгую типизацию TypeScript. Не скрывайте несовпадения типов через `as`, если можно корректно описать реальную структуру данных.
- Используйте `type`-импорты там, где этого требует `verbatimModuleSyntax`.
- Редьюсеры должны оставаться чистыми. Сохранение в браузере реализуйте через listener middleware, подписку на Store или другую внешнюю по отношению к редьюсерам границу.
- Используйте флаги состояния RTK Query для отображения загрузки, ошибки, пустого и успешного результата.
- Пропускайте запрос, если отсутствует обязательный параметр маршрута или поиска.
- Формируйте query-параметры через поле `params` RTK Query, а не ручной конкатенацией строк, особенно для необязательных и пользовательских значений.
- Сохраняйте существующий подход с CSS Modules. Общие визуальные компоненты размещайте в `src/common/components`.
- Добавляйте доступные подписи элементам управления, состоящим только из иконки, и используйте семантические формы, чтобы поиск отправлялся клавишей Enter.
- Не редактируйте сгенерированные файлы в `dist/` вручную.
- Не подключайте второй менеджер пакетов и не пересоздавайте lock-файл без необходимости изменения зависимостей.
- Новые инструкции, пояснения, документацию и комментарии пишите на русском языке, если пользователь не указал другое.

## Особенности TMDB

- Для авторизации используется TMDB v4 read access token, передаваемый как `Bearer <token>`.
- Пути изображений TMDB являются относительными. URL постеров, фонов и фотографий актёров сейчас формируются в компонентах через `https://image.tmdb.org/t/p/...`.
- Эндпоинты списков TMDB возвращают `total_pages`, но клиент не должен запрашивать страницы выше поддерживаемого TMDB предела — обычно 500. Ограничивайте пагинацию перед отображением и выполнением запроса.
- Многие поля изображений и дат TMDB могут быть `null` или пустыми. Типы ответов и запасные варианты интерфейса должны это учитывать.
- Переменные окружения Vite встраиваются в браузерный bundle. Не считайте `VITE_API_KEY` приватным секретом; если требуется скрыть токен или защититься от злоупотреблений, используйте бэкенд-прокси.

## Известные проблемы и технический долг

Ниже перечислены существующие проблемы, которые не следует копировать в новый код:

1. `src/features/main/ui/Main.tsx` вызывает `Math.random()` во время рендера. Текущие правила React Hooks считают такой рендер нечистым, поэтому ESLint завершается с ошибкой.
2. `app-slice.ts` и `favoritesSlice.ts` читают или изменяют `localStorage` при инициализации среза или внутри редьюсеров. Побочные эффекты в редьюсерах нарушают принципы Redux и усложняют тестирование, SSR и обработку ошибок.
3. Переключатель темы обновляет только Redux и `localStorage`. Значение не используется классом темы, CSS-переменными или MUI ThemeProvider, поэтому оформление визуально не меняется.
4. `Favorites.tsx` приводит сокращённый тип `FavoriteMovie` к полному `Movie`. Сейчас `Card` случайно использует только сохранённые поля, но дальнейшее изменение карточки может вызвать ошибку времени выполнения. Следует выделить общий тип данных карточки.
5. Большинство маршрутов не отображает состояния загрузки и ошибки запроса. Ошибка TMDB часто выглядит как пустая страница.
6. Запросы страницы фильма принимают неопределённый ID и не используют `skipToken` или `skip`. При изменении контракта маршрута это может привести к запросу `/movie/undefined`.
7. Пагинация использует исходное значение `total_pages` и может предлагать неподдерживаемые TMDB страницы выше 500.
8. Номер страницы поиска хранится отдельно от URL. При навигации назад или вперёд поисковый запрос может измениться, а номер страницы остаться от предыдущего запроса.
9. Production-сборка предупреждает о размере основного JavaScript-чанка свыше 500 КБ. Первым улучшением стоит рассмотреть ленивую загрузку на уровне маршрутов.
10. В репозитории есть текст с повреждённой кодировкой, например знак авторского права в подвале и некоторые стрелки. Сохраняйте исходные файлы в UTF-8 и исправляйте видимые пользователю строки при изменении соответствующих файлов.

## Проверка изменений

Перед завершением работы:

1. Убедитесь, что учётные данные и `.env`-файлы не подготовлены к коммиту.
2. Запустите TypeScript/build и ESLint.
3. Проверьте для затронутого маршрута состояния загрузки, успешного ответа, пустого результата и ошибки, если они применимы.
4. При изменении API проверьте сформированный URL, заголовок авторизации, условия пропуска запроса и границы пагинации.
5. При изменении избранного или темы перезагрузите страницу и проверьте сохранение состояния.
6. При изменении маршрутизации проверьте как переход внутри приложения, так и прямое открытие вложенного URL.
7. Укажите отсутствие тестов, если изменение не добавляет тестовый набор.
